# 🐾 Pawsture

반려견 슬개골 탈구 방지 걸음 분석 서비스입니다.

## 🛠 Tech Stack

- **언어 / 프레임워크:** TypeScript, Next.js (App Router), React 19
- **스타일링:** Tailwind CSS v4
- **상태 관리:** TanStack Query (서버 상태), Zustand (전역 상태)
- **배포:** Vercel

## 🚀 Getting Started

```bash
# 의존성 설치
pnpm install

# 로컬 개발 서버 실행
pnpm dev
```
